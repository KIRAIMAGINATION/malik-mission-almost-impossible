# Малик: миссия невыполнима (почти)

Готовая статическая браузерная аркада на русском. Откройте index.html в браузере. Сборка, установка зависимостей и сервер не нужны.

Управление: стрелки влево/вправо, вверх или пробел для прыжка. На сенсорных устройствах доступны кнопки. Звук включается кнопкой. Пауза — кнопка или Escape. После падения Малик возвращается на последнюю безопасную платформу.

## Публикация

В настройках репозитория: Settings → Pages → Deploy from a branch → main → / (root) → Save. Через несколько минут адрес появится на этой странице.

## Проверено

Автоматическая симуляция реальной физики от начала до финала: 86 платформ, пять сообщений, один постановочный провал, три финальные реплики, окно ошибки, возврат после обычного падения и перезапуск. Проверен запуск в браузере desktop. Реальный iPhone и звучание требуют ручной проверки на устройстве.

Чистое прохождение без чтения: около 135 секунд. Обычное прохождение с диалогами и попытками рассчитано на 3–5 минут.

## Изображения

Персонажи нарисованы программным pixel art по фотографиям и описанию. Исходные личные фотографии в репозиторий не включены. Последняя согласованная пиксельная отрисовка в истории недоступна, поэтому точное совпадение с ней пока не подтверждено.
