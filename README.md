# Малик: миссия невыполнима (почти)

Готовая статическая браузерная аркада на русском. Откройте index.html в браузере. Сборка, установка зависимостей и сервер не нужны.

Управление: стрелки влево/вправо, вверх или пробел для прыжка. На сенсорных устройствах доступны кнопки. Звук включается кнопкой. Пауза — кнопка или Escape. После падения Малик возвращается на последнюю безопасную платформу.

## Публикация

В настройках репозитория: Settings → Pages → Deploy from a branch → main → / (root) → Save. Через несколько минут адрес появится на этой странице.

## Проверено

Автоматическая симуляция реальной физики от начала до финала: 65 платформ, пять сообщений, один постановочный провал, три финальные реплики, окно ошибки, возврат после обычного падения и перезапуск. Проверен запуск в браузере desktop. Реальный iPhone и звучание требуют ручной проверки на устройстве.

Чистое прохождение без чтения: около 102 секунд. Обычное прохождение с диалогами и попытками рассчитано на 2–4 минуты.

## Изображения

Персонажи обновлены по согласованному листу: чёрная одежда Малика, короткие чёрные волосы, лёгкая щетина, опущенный капюшон; у Кирилла светлые волосы, тёмные очки и чёрная толстовка. Атлас содержит 24 кадра для ожидания, бега, прыжка, падения, приземления, поворота и реплик. Исходные личные фотографии и лист с референсами не публикуются.

Графический атлас: `assets/characters-v2.png`, создан встроенным инструментом генерации изображений по согласованному референсу. Точный промпт и описание кадров: `assets/characters-v2-prompt.txt`.

## Обновление маршрута

Длина пути сокращена с 15 130 до 11 347,5 игровых единиц (ровно на 25%). Между обычными облаками — 71–83 единицы вместо 36. Пять локаций: Москва, леса и озёра, европейский закат, чешские холмы и Прага. Фон сохраняет координаты объектов при прокрутке, палитры и силуэты плавно смешиваются.
